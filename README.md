# AI-Driven Product Strategy and Production Planning

## Overview

An AI-driven manufacturing intelligence system designed to support
product strategy and production planning through operational analytics,
machine learning, sustainability evaluation, data quality verification,
and optimization techniques.

## Key Features

-   Production planning using the Wagner-Whitin algorithm
-   Manufacturing data analysis and operational analytics
-   Random Forest and Gradient Boosting models
-   Sustainability evaluation
-   Carbon footprint analysis
-   Recyclability index
-   Energy-efficiency analysis
-   Pareto frontier analysis
-   Multi-objective optimization
-   Platform optimization and synergy analysis
-   Z-score anomaly detection
-   Confidence interval analysis
-   Data quality verification
-   Interactive Flask dashboard

## Technology Stack

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Flask, HTML, CSS,
JavaScript.

## Dataset

The project uses `hybrid_manufacturing_categorical.csv` for
manufacturing analysis, prediction, optimization, and dashboard
visualizations.

## Main Modules

### Production Planning

Uses a Wagner-Whitin based approach for fixed-horizon production
planning and cost analysis.

### Machine Learning

Uses Random Forest and Gradient Boosting models for predictive
manufacturing analysis.

### Sustainability Analysis

Evaluates carbon intensity, carbon footprint, recyclability, and
energy-efficiency metrics.

### Optimization

Analyzes trade-offs between cost, quality, and sustainability using
Pareto frontier analysis.

### Platform Optimization

Analyzes shared machine-operation combinations and calculates synergy
scores for product-family platforms.

### Data Quality Verification

Uses Z-score anomaly detection, confidence intervals, and source
credibility analysis.

## Dashboard

The Flask dashboard brings together manufacturing analytics, prediction
results, sustainability metrics, optimization analysis, data-quality
analysis, and production-planning insights.

## How to Run

``` bash
git clone https://github.com/VarunJanarthanam/AI-Driven-Product-Strategy-and-Production-Planning.git
cd AI-Driven-Product-Strategy-and-Production-Planning
pip install -r requirements.txt
python app_enhanced.py
```

Then open the local Flask URL shown in the terminal, typically
`http://127.0.0.1:5000/`.
